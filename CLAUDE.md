# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Read [AGENTS.md](AGENTS.md) first; it is the single source of rules for this repo. [CONTRIBUTING.md](CONTRIBUTING.md) explains how to propose a change.

Claude-specific notes:

- This is a plain Markdown governance guide with no build, test or lint commands. Check changes by reading the rendered Markdown, not by running anything.
- Never commit secrets, client material or anything traceable to a real engagement.
- Commit or push only when asked.
